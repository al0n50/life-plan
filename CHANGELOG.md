# Changelog

Known-good versions of `main`. Each one gets a git tag and a GitHub release.

## v1.0.0: On-device planner (2026-11-17)

**What's in it**
- **Financial engine:** income and paycheck simulation with tax estimates, bills, debt payoff, savings goals, career phases and life events (45 engine tests).
- **Screens:** Home, Calendar, Life, Log, More, plus accounts, debt, expenses, goals, income, paycheck, plan, review and first-run onboarding.
- **On-device storage:** plans are saved on the device, with a versioned format and upgrade steps so app updates keep your data.
- **Builds:** one Expo codebase for web, iOS and Android. The web build deploys automatically from `main`.

**Next:** optional accounts with cloud sync across web and phone.
